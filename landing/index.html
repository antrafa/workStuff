The agents read. You decide what changes.

workStuff runs commands on your machine and against real clusters, so every default leans toward doing less.

  • Read-only AI. Claude gets only Read, Grep and Glob; Codex runs in its read-only sandbox; Antigravity runs inside bubblewrap.
  • Clusters by risk. PRO, and any kubeconfig it cannot classify, never accepts a write. DES never deletes.
  • Scoped access. The agent gets a temporary kubeconfig with only the context you picked.

One script installs, updates and removes.

No token and no sudo: access is your own git credential, and nothing is written outside your home folder.

  1. Clones the repository into ~/.local/share/workstuff.
  2. Checks Node 22.18 or newer, in your PATH or in nvm.
  3. Closes the panel if the launcher opened it.
  4. Updates the code with git pull; with local changes, it warns and moves on.
  5. Installs the dependencies and adds a workStuff launcher to the app menu.
Terminal
git clone https://github.com/antrafa/workStuff.git ~/.local/share/workstuff && bash ~/.local/share/workstuff/landing/install.sh

Update: bash ~/.local/share/workstuff/landing/install.sh. Remove: add --uninstall.

PowerShell
git clone https://github.com/antrafa/workStuff.git "$env:LOCALAPPDATA\workStuff"; powershell -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\workStuff\landing\install.ps1"

To update, run only the second part; to remove, add -Uninstall to it. Windows support is young: the winget fixes have not been tested on real machines yet.
